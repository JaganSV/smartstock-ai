# BP §10.2 — Role matrix (binding)
Source: SmartStock AI Blueprint v1.0 §10.2. Encoded as ROLE_MATRIX in backend/app/core/rbac.py and verified by
tests/unit/test_rbac.py (AC-3.2). Do not add, remove or rename capabilities without an ADR.

| Capability key            | Description                               | ADMIN | INVENTORY_MANAGER | ANALYST | EXECUTIVE |
|---------------------------|-------------------------------------------|-------|-------------------|---------|-----------|
| view_inventory            | View dashboard, risk, analytics, products | Y     | Y                 | Y       | Y         |
| ask_ai                    | Ask copilot / knowledge assistant         | Y     | Y                 | Y       | Y         |
| generate_recommendations  | Generate replenishment recommendations    | Y     | Y                 | N       | N         |
| decide_recommendations    | Approve / adjust / reject recommendations | Y     | Y                 | N       | N         |
| export_approved_csv       | Export approved recommendations CSV       | Y     | Y                 | N       | N         |
| generate_executive_report | Generate executive report                 | Y     | Y                 | N       | Y         |
| manage_documents          | Upload / manage knowledge documents       | Y     | N                 | N       | N         |
| recalculate_analytics     | Trigger analytics recalculation           | Y     | N                 | N       | N         |
| view_governance           | View audit log and AI interactions        | Y     | N                 | N       | N         |

Notes: GET /auth/me is open to any authenticated role. Listing reports/documents falls under view_inventory.
/admin/audit-log and /admin/ai-interactions use view_governance.
